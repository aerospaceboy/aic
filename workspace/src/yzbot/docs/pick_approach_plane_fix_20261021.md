# 预抓取接近阶段侧向绕行修复（2026-10-21）

## 问题

用户确认异常发生在机械臂靠近物块、尚未闭合时。最近一次异常参考为
`manual-20261021T141942` 的 `red_cube_3`：接近阶段约 4.19 秒，其他轮次通常约
2.28 秒，最终下降检查仍通过。之前修复的竖直下降没有覆盖这一阶段。

实际状态链为：上一件放置后六关节归零 → 缓存货位跳过扫描 → 从全零状态直接求 IK
并执行关节空间接近。全零工具朝上，KDL 以近奇异状态为种子可以选到不同的构型。
只读 IK/FK/规划复现（未执行）：同一目标 `(0.36012,-0.01558,0.1216)`、四元数
`(0,1,0,0)`，微小种子扰动可以得到肩部/腕部约 −2.48° 或 177.52° 两种解。
对应规划约 2.21 秒或 4.10 秒，后者采样偏离目标垂直平面约 337 mm。
这些是模型复现，不是对过去实际轨迹的完整还原。

## 实现

修改 `mybot/pick_place_moveit.py`，正常抓取和旧版循环共用 `move_pick_approach()`：

1. 从目标 XY 求穿过机械臂基座与目标的垂直平面，yaw=`atan2(y,x)`。
2. 使用两个明确前伸弯曲的 IK 种子，启用原有碰撞检测。排除关节越界、非有限值及
   joint1/joint4/joint6 不在目标平面的解；对剩余解比较关节运动代价。
3. 必要时先在高处对齐侧向关节：joint1=yaw，joint4=0，joint6=yaw。
   对齐规划约束俯仰关节保持当前值附近，避免对齐时另行折臂下降。
4. 接近段增加 MoveIt 路径约束，joint1/joint4/joint6 在相应平面参考角 ±0.020 rad
   内运动。完成后检查真实关节反馈，再进入既有高度标定、竖直下降与闭合逻辑。
5. 不接受从低处或肩部反向姿态直接进行高处对齐；对齐或平面规划失败即结束该次
   抓取，不回退到无平面约束的接近规划。

高处对齐的起始 TCP 高度要求为基座坐标系 Z≥0.250 m。它是新增的拒绝条件，不是
放宽物块抓取、携带或碰撞安全窗口。目标平面随物块横向位置确定，不强迫偏置目标
落在车体固定 XZ 平面中。高处对齐本身负责由原来的扫描平面过渡到目标平面；其后
才严格执行接近平面约束。

两轮动态避障监测均未报告碰撞，但都未记录原始 obstacle_1 的有效响应；没有独立
接触流审计。本报告证明抓取接近修复和搬运回归，不作为正式竞赛全项验收。

本次修复限制侧向绕肩和侧摆，工具从朝上到朝下的正常俯仰仍在目标垂直平面中完成。
高处对齐允许必要的小角度转向，不能将整条动作解释成所有关节完全不旋转。
