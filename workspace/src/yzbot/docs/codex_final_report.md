## 5. 已知非致命提示

- Gazebo pose/contact queue limit：各打印一次，表示旧的可视化/接触消息被丢弃，
  不影响控制、抓取或落区。
- MoveIt 未配置 OctoMap 3D 更新插件：打印一次；当前系统仍使用 MoveIt 规划场景
  和碰撞检查。若后续需要在线体素地图，可单独接入 RGB-D PointCloud2 插件。
- 本地 LLM 服务不运行时会记录一次连接失败，随后使用规则解析；该降级是设计行为。

## 6. 比赛使用建议

1. 先登录 Ubuntu 桌面，确保 RGB-D 可复用 Xwayland 渲染。
2. 比赛前完成一次 `COMPETITION_ACCEPTANCE=PASS`。
3. 没有稳定的本地模型服务时使用 `use_llm:=False`，保证任务解析可预测。
4. 在宿主机保持面板打开，观察题目、抓取状态、路径和剩余时间。
5. 每轮结束保存 `/tmp/competition_acceptance.json` 或
   `/tmp/competition_timed_acceptance.json` 作为验收证据。
