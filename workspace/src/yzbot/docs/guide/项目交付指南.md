# 竞赛机器人项目交付指南(2026-09-06)

本文是项目统一入口:系统是什么、怎么跑、改哪里、如何验收。历史细节见
`docs/HANDOFF_PROMPT_V12.md` 与 `docs/AGENT44_WORKLOG.md`。

## 1. 系统一页纸

- **栈**:ROS2 Humble + Gazebo Classic + Nav2(Smac2D→RPP)→ 速度平滑 →
  Collision Monitor → /cmd_vel_safe → 底盘;机械臂 MoveIt 常驻服务。
- **任务流**:题目 → task_parser(LLM 解题+严格校验)→ TaskPlan →
  MissionStateMachine(逻辑作业)→ coordinator 选同色实体 →
  task_navigator 安全锚点/停靠 → 视觉+机械臂抓放 → 真值验证。
- **选块**:只锁颜色顺序;同色实体子集/顺序/接近侧由离线 DP 表
  (`tools_demo/config/cube_order_policy.json`)驱动,未列任务回退距离评分。
- **安全链**:真实墙体、Collision Monitor(NearSlow/BodyStop)、载荷包络、
  roll/pitch 限制;任何优化不得扩验收边界、缩 footprint、全局提速。

## 2. 成绩现状(2026-09-06)

- 48 题全分布(旧布局):45 题 5/5 验收,26 题运动 <300 s。
- 新布局(本轮):blue4/blue5 移至中南走廊后,
  1rC_4bA **270.9 s**、1rA_4bB **267.5 s**、1bA_4rB 309.3 s 均全验收;
  最难的 4 蓝→C 族稳定 5/5(347.8/362.2 s),运动 <300 s 仍未全达。
- 完整比赛墙钟 = 出题 + LLM 解题(实测 21–23 s)+ 展示 + 运动;
  运动预算建议 ≤270 s。
