# Safe 300-Second Sprint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish repeatable startup, restore safe five-cube reliability, then reduce a measured 5/0 runtime below 300 seconds.

**Architecture:** Keep launch tooling, manipulation reliability, and navigation performance as separate validation stages. Each stage has a failing regression check, a single scoped change, and a full Gazebo acceptance gate before the next stage begins.

**Tech Stack:** ROS 2 Humble, Nav2, Gazebo Classic, MoveIt 2, rclpy, pytest, Bash, PowerShell.
