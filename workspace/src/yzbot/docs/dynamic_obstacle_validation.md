## 3. 真实感知与运动控制

- 障碍控制器使用 `/gazebo/set_entity_state` 驱动运动，再通过 `/gazebo/get_entity_state` 读取 Gazebo 真值后发布；GUI/监控不使用命令位置冒充真值。
- 删除了基于机器人里程计把障碍物瞬移到“让行点”的逻辑，不存在 yield/teleport 捷径。
- 轨迹按固定仿真步推进，每个定时回调最多接受一步；服务调用有 1 s 超时、取消与重试，禁止因仿真时间追赶一次跨越多步。
- 激光 `range_min` 从 0.50 m 改为 0.10 m；局部 voxel obstacle layer 使用 `/scan` 的 marking 与 clearing。
- 60.046 s 轻量真值连续性复测获得 469/462 次更新，最大相邻步长 0.002/0.011 m，最大墙钟速度 0.0201/0.1171 m/s，无瞬移。
- 305 s 综合监测中的最大回调间隔为 1.54 s；其较大采样位移来自综合监测进程在 HTTP/代价地图负载下漏取中间回调，并非 Gazebo 跳变。上面的专用连续性复测消除了该观测混淆。
- 两障碍物各出现 1 个启动期 `GetEntityState` 未成功样本，随后自动重试；305 s 内其余 Gazebo 真值均持续更新且边界违规为 0。
