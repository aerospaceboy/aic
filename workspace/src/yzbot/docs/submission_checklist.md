# 提交与赛前核对

- 按主办方最新要求准备源码、技术文档、录像和团队信息；规则原文件保留在根目录 `rules/`。
- 使用 `scripts/package_submission.py` 生成源码 ZIP，避免直接压缩整个开发目录。
- 解压后校验 `SHA256SUMS`，在 Ubuntu 22.04/Humble 环境重新构建并运行测试。
- 确认目标机器的图形桌面、Gazebo、RViz、CoStudio、coBridge 及网络正常。
- 配置当前用户的 API Key，确认正式模型解析成功。源码、录屏与提交包不得包含私有凭据。
- 一键启动输出 `MANUAL_PROBLEM_MODE=PASS` 后，提交题目与对应映射规则。
- 核验每件视觉目标、抓取结果、实际落区、五件完成且无跳过、总用时与安全状态。
- 按规则核对真实有效避障次数；未自然触发的指标不能补写为成功。
- 保留机器人模型、地图、场景、许可证、扩展构建产物和运行所需配置。
- 确认 ZIP 不含 Git 历史、AI 交接文档、历史验收/工作记录、备份场景、构建缓存和旧日志。
