# 2026-10-13 移动障碍物优化目标与原则

只改本机实践项目，桌面 20261012T234726 冻结目录、ZIP、侧车不改、不重打。开始与结束读校验；此前计时／机械臂／通信／模型改动均保留，先建立源码收据与原始差异。

目标：先验证激光驱动的动态导航可用，再删除两块低效紫色 preview 移动板，用两个安全且必经的新移动障碍替代。不修改物块、货架、zone 或小车速度；不动解题、计时、机械臂、任务选择等无关代码。保留出生走廊原有两障碍。

原则：

1. 感知与规划用带时间戳的激光和 TF，补偿自身运动，估计障碍物方向与速度。真值仅作验收及现有安全守卫，不作为新导航规划的障碍位置来源。
2. 把短期运动预测变成 Nav2 可见的动态风险，不直接盲目向运动反方向转弯。只有地图、实时感知和足迹检查都允许时才从正在腾出的空隙绕行；否则在危险扫掠之外安全等待，现有碰撞检测和阈值保持。停车不等于安全，不能在连续障碍的运动线上靠停车兜底；规划间距必须与最终守卫的停车范围一致。
3. 移除紫板及其永久扫掠禁行带：它们本来就被全局规划绕开，且一块覆盖狭窄通道，不能将这种静态绕远称为动态避让。其他静态安全禁行带保留。
4. 用户进一步明确：出生点到原点已有原障碍，不得在这一段添加新障碍。该段及原两个障碍保持原样。新位置必须在取货／送货共用通道，通过任务数量、货物分布、A/B/C 路径和地图瓶颈分析证明整轮覆盖，不逐题跑 24／48 组合。若某位置只能覆盖部分任务，直接排除，不称为全覆盖。新障碍连续运动，不因机器人靠近而退走、暂停或跳变。
5. 检查完整扫掠体而非中心点，包含实体尺寸、墙／货架／物块／zone 的距离、两障碍相互距离、可通行安全空隙；运动初始姿态与控制器相位一致。
6. 选固定 R2 基线（3红B＋2蓝A）和较慢 R1（1红C＋4蓝A）中的一到两个做前后配对，头less、无 CoStudio／RViz／SLAM。记录全五件、终态、落区真值、实际导航响应、运动耗时／墙钟／RTF，不以仅接近或停一下算绕避通过。
7. 性能门：不提高速度抵消障碍开销，不放宽 300 s、安全净距、足迹或判定条件；优先消除原紫板导致的绕远与无效等待。若对照显示变慢，继续优化或明确不能验收，不把一次通过当无退化保证。

阶段顺序：原配置真实基线与感知记录 → 地图及必经通道几何证明 → 传感器预测避障单元／导航验证 → 新障碍几何与连续性检查 → 少量完整任务前后对照 → 受限差异和冻结哈希复核、交付实践报告。不生成新冻结版本。
