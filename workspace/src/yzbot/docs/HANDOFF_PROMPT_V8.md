## 2. 目标优先级和合法空间

严格按以下顺序做决策：

1. 所有任务 `completed=5, skipped=0`，真值投放正确，无物理碰撞/翻滚/载荷越界；

48 轮：先单测与静态审计，再跑一个最相关高风险样本，最终候选才做紧凑覆盖矩阵。

## 3. 当前稳定设计

- 两个橙色圆柱位于 x=8.5 和 x=5.0 的无墙列，采用 `triggered_crossing`。
- 每个任务首段固定经过 `(12.6,-0.6)->(0,0)`，确保两个障碍实际被遇到；障碍让行后
  回到 home 并退出本轮干扰。
- Nav2 使用 Smac2D + RotationShim + RPP；所有静态绕行锚点均来自实际墙体/货架风险，
  即使名称含 obstacle_2 也不能按“旧动态障碍已退休”整段删除。
- 机械臂使用低位运输、抓取锚定、载荷窗口、真值投放与失败恢复；精确任务颜色顺序不可

不可突破的红线：`robot_radius=0.28`；BodyStop 0.26；NearSlow 0.38、ratio 0.70；
RPP collision horizon 0.65；roll/pitch 0.15；payload envelope 0.35；pickup speed 0.80；
zone egress 最大 0.70；不得缩小 footprint、修改世界墙体或降低真值验收。

## 5. 推荐的下一步 300 秒方案

### 已实现：严格锚点的连续全局路径

当前实现没有使用默认会 `RemovePassedGoals` 的树。专用行为树只执行一次
`ComputePathThroughPoses goals -> FollowPath path`，让 Smac 生成必须穿过全部安全锚点的
完整路径，RPP 不停车连续跟随。TaskNavigator 必须保存原始 pose 列表；批量动作只尝试
一次，任何拒绝、abort、慢进度或动态倒车都立即恢复原串行 `NavigateToPose` 队列。

已落实的边界：

- 排除含 `universal_*` 的出生双障碍路线，保持现有确定性避障与取消语义；
- 已验证最敏感的 `C_EXIT -> BLUE_CUBE_3`，路径安全通过全部既有锚点；
- 服务器不可用、发送失败、拒绝、abort 或慢进度均恢复完整串行队列；
- C、B 投放及 blue3/4/2 的四锚点路线已在五物块轮一次成功。

该方案已在最坏压力分布实测节省 37.7–70.9 秒，且没有改变墙距或碰撞阈值。
后续不得恢复默认 waypoint-removal 树，也不得放大通过半径。

### 方案 B：分路线的中间路点交接

若方案 A 不稳定，为“中间 Nav2 锚点”新增独立交接距离，最终 dock 仍保持 0.20 m。
只能在直线、宽净空路段从 0.20 小步试到 0.30/0.35 m；C 墙角和下部 L 墙路线使用更紧的
per-route 值。它仍然启动下一段 Nav2，不允许从中间点盲开直控。预期收益较小但风险低。

### 方案 C：墙钟性能与传感器负载

任务预算使用 `time.monotonic()`，不是 `/clock`。每轮同时记录 `gz stats -p`；实时倍率低于
0.9 的结果只算功能证据，不作为算法性能比较。headless 单独无收益，但可以逐一审计 RGB-D、
点云、SLAM evidence、dashboard 和诊断节点的更新率；只降低任务不需要的发布频率，不能关闭
RGB-D、激光、碰撞监控或真值链。VM 异常高负载持续时停在干净状态，请用户重启，不要把
性能饥饿误修成路线问题。

### 方案 D：用成功轮速度报告建立下界

在完整 5-blue→B 成功轮保存 `/tmp/competition_speed_profile.json`，把每次导航、机械臂、
直接停靠、等待/恢复与实际 Smac 路径长度关联。优先消除固定停车/恢复；不要再提高全局
`desired_linear_vel`，当前普通转弯已约 1.21 m/s、锐转约 0.97 m/s，盲目提速更可能在墙角
回归。若安全路径长度与机械臂下界本身已超过 300 秒，要把定量下界写明，而不是伪造达标。

## 6. 高效验证流程

每个单变量按以下门禁执行：

1. 备份并确认工作树；
2. `git diff --check`、`py_compile`、相关契约/数学/风险测试；
3. 非存量 lint 的完整 Python 回归（稳定源码基线为 318 passed, 1 skipped；实验新增
   两项测试时曾显示 320 passed, 1 skipped）；
4. 只跑一个最相关分布，记录 `gz stats -p`、5/5、skipped、双障碍响应、BodyStop、实体真值、
   roll/pitch 与最小中心距；
5. 失败立即清理进程并恢复该单变量，不叠加第二项修改；
6. 候选稳定后跑紧凑矩阵：同色最远 B/C、C 出口到南部蓝块、A/B 混色近 300 秒、两种
   颜色顺序；最终版本才覆盖全部 48 种。

每轮全量重启，清理 `/tmp/ros2*`，等 mission idle、机械臂 persistent server 和 DDS 稳定
后再发题。任务发布后必须看到 parser 接收日志才算有效轮次。
